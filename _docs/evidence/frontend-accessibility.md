The viewport cases read computed geometry and color from rendered controls and navigation links. The 200% case uses a 720 CSS-pixel viewport, equivalent to half the width of the 1440px desktop viewport; it does not change the host browser’s actual zoom setting. The suite uses focused, project-specific assertions and is not an exhaustive axe/WCAG audit. It does not establish screen-reader usability, human visual acceptance, or manual keyboard acceptance.
