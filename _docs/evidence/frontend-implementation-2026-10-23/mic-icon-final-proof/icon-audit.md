## Style and accessibility evidence

The approved owner contract requires Lucide with the Affect outline treatment: 24×24 viewBox coordinates, no fill, `currentColor`, stroke width 1.1, rounded caps/joins and viewBox-relative scaling. The current JSX sets `strokeWidth={1.1}` on shell, OTP, Credits, Microphone, New dub, Processing, Projects, Recording, RecordingTransport and Result icon instances. Account and AccountLinking apply `stroke-width: 1.1` in screen CSS to their SVG icon classes. Direct icon instances are marked decorative with `aria-hidden`; icon-only controls carry their action name on the containing button/trigger. Root's rendered runtime metrics directly verify Menu and Sheet X: viewBox 24×24, fill none, currentColor, width 1.1, round caps/joins, `aria-hidden=true`; Menu is 24px, X 16px within a 48px close target. See [metrics](../shell-rendered-metrics.json) and the [mobile shell capture](../shell-mobile-menu-en-390.png).

Most screen icons have explicit `strokeWidth={1.1}` at the use site. Account and AccountLinking are the two CSS-treated groups: Account's section/method/action selectors and AccountLinking's back/eyebrow/step/method/check selectors set 1.1. Lucide supplies the shared outline SVG defaults (24×24 viewBox, no fill, currentColor stroke, rounded line ends/joins); the rendered Menu/X measurement confirms those defaults in this app. The new Projects menu uses Lucide `MoreHorizontal` and `Trash2` at 1.1. Its Radix dropdown dependency supplies menu behavior, not another icon family.

Provider-owned Google branding remains a brand asset and is not counted as a UI icon family. The microphone level track, CSS button loader and native audio controls are state/transport UI, not alternate glyph sources. The current source scan found no imported HugeIcons, default shadcn icon set or second React icon package in app TSX.

## Clean/Light contour and adaptation map

Before the comparison, the applicable [Button Clean source](../../affect-ui-clean-light/source/components/button/Clean/button-clean.md.txt) and matching [Button Light initial PNG](../../affect-ui-clean-light/source/components/button/Clean/Light/01-initial.png) were inspected. Its `TrashIcon`, `ArrowUpIcon`, `PlusIcon`, `CopyIcon`, and `UploadIcon` examples establish button icon placement and outlined state treatment. The current Lucide exports are replacements chosen for application action semantics; the implementation does not copy the reference SVG paths or assert pixel-identical glyph contours. `Trash2` is the app's delete-action Lucide glyph; `ArrowRight` remains for rightward navigation while `ArrowUpRight` means opening/continuing to a destination. The current inventory has no `Plus`, `Copy`, or `Upload` action glyph, so those reference examples do not map to current app actions.

The [Profile menu Clean source](../../affect-ui-clean-light/source/components/profile-menu/Clean/profile-menu-clean.md.txt) and [matching Light initial PNG](../../affect-ui-clean-light/source/components/profile-menu/Clean/Light/01-initial.png) were inspected as a reference for small outlined menu glyphs. Its Settings/Docs/Apps destinations are explicitly outside the Dubbed shell hierarchy; the application does not import `Settings` or `FileText`, and does not reproduce those destinations. The adopted iconography note's prior contour examples for `Settings` and `FileText` (Lucide source 0.468.0) therefore do not apply to the current asset inventory.

The app deliberately retains Lucide's own path geometry instead of copying Affect SVG paths. The app's `Trash2` is the semantic delete-action replacement for the reference `TrashIcon`; the contours differ. App navigation/launch uses `ArrowUpRight` where the reference example is `ArrowUp`; this is the destination-link adaptation, not a claim of contour identity. The reference `UploadIcon` is not mapped to app `Download` because the actions are opposite. Among the inspected Button/Profile Menu source pairs, no equivalent contour is specified for this inventory's `Mic`, `RefreshCw`, `RotateCcw`, `RotateCw`, `MoreHorizontal`, `Play`, `Pause`, `Download`, `ArrowLeft`, `ArrowRight`, `Check`, `Globe2`, `Link2`, `LogOut`, `Menu`, `Pencil`, or `X`; these are named Lucide semantic choices. This is scoped to the inspected adopted examples, not a claim about every asset in the Affect library.

## Audit boundary

This closes the current-source inventory and adds rendered samples across the implemented screen families. It records exact package version/integrity, source icon names, the 14/16px shared control slots, contextual 17/20px Account tiles, the 48px Projects phone override, shell metrics and a computed Play/Pause sample. The verified OTP Check state is the one named icon-state screenshot omission. This does not claim pixel-identical Affect paths, per-instance DOM measurements for every state, universal browser contrast or hardware assistive-technology certification. Mock screenshots do not establish provider branding, real microphone hardware, real audio output, production services or a backend. No screen-owner product code was changed for this audit.
