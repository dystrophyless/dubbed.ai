# Shell source mapping and rendered checks

The applicable sources are [_docs/frontend-flows/01-landing.md](../../frontend-flows/01-landing.md), [_docs/frontend-flows/affect-ui-clean-light-reference.md](../../frontend-flows/affect-ui-clean-light-reference.md), [_docs/frontend-flows/affect-ui-clean-light-adoption.md](../../frontend-flows/affect-ui-clean-light-adoption.md), and [_docs/frontend-flows/design-tokens.md](../../frontend-flows/design-tokens.md). The landing flow settles a 768 CSS-pixel breakpoint, 32px desktop and 16px phone gutters, 32/40 desktop and 24/32 phone headings, 1200px working-content cap, 16/24 body, 14/20 supporting text, and compact desktop / 48px phone actions. The Clean/Light reference maps the small, medium, and large Button variants to 24px, 28px, and 32px heights, 6px radius, source-specific horizontal padding/gap/icon sizes, and Mabry Medium 12/16 or 13/20 labels. The phone adaptation retains a 48px target and Mabry Medium 16/24.

| Reference component or state | Shell implementation | Exact source value or adaptation |
|---|---|---|
| Compact primary button | Native `<button>` with the `buttonVariants` CVA variant; shadcn Button interaction semantics | Dark primary, 6px radius; lg desktop height 32px, 12px horizontal padding, 6px gap, Medium 13/20. Phone uses 48px minimum height, 16/24. Hover color/background feedback 140ms ease; press transform 160ms with source shared easing. |
| Small navigation button | Native button/link semantics with CVA styles | Height 24px, 8px horizontal padding, 4px gap, Medium 12/16, 6px radius. Compact size is only used for desktop navigation. |
| Header locale affordance | Labeled native `<select>` with EN/RU values | The source shows a compact EN/RU affordance but does not specify its widget, open menu, or keyboard state. The implementation uses native select semantics and native option presentation as an explicit accessibility adaptation; its selected control is styled to the compact header. Size is 48×32 desktop and at least 48×48 on phones. It is not a custom Radix Select. |
| Text input | Native `<input>` plus associated `<label>`, hint, error and `aria-describedby` | Preserves platform typing, autofill and keyboard semantics while allowing source-derived input styling and explicit error text. |
| Mobile menu Sheet | Radix Dialog with localized title, description and close button; CVA button and Lucide X | Uses the source menu/sheet treatment with modal focus, Escape and close behavior; local menu geometry is bounded to 360px and full-height. The current source gap is the compact locale option popup, which intentionally remains browser-native. |
| Error notification | Role `alert` for errors and `status` for neutral/success states | Code-to-copy mapping is EN/RU; raw adapter messages and field prose do not cross into user-visible copy. |
| Keyboard focus | `:focus-visible` outline | Explicit accessible backing: 2px solid `#0060E2`, 2px offset. Captured on the skip link as `rgb(0, 96, 226)`. |
| Reduced motion | `prefers-reduced-motion: reduce` | Functional content remains; transitions/animations compute to `0.01ms` and root scroll behavior becomes `auto`. |

Mabry Pro replaces the reference's Inter by explicit owner direction. `font-synthesis: none` is active and browser checks confirm the Mabry family loads before capture. The support link is explicitly styled; its computed default color is `rgb(0, 96, 226)` (`#0060E2`), distinct from the browser's default link blue. The shell does not add a persistent sidebar or reference-only marketing sections.

Rendered browser measurements and screenshots are in [shell-rendered-metrics.json](shell-rendered-metrics.json), [shell-landing-en-desktop.png](shell-landing-en-desktop.png), [shell-landing-en-768.png](shell-landing-en-768.png), [shell-landing-en-767.png](shell-landing-en-767.png), and [shell-landing-ru-phone.png](shell-landing-ru-phone.png). Viewport widths 1440, 768, 767, 390, and 720 were checked with no horizontal overflow. The 720px case is an effective-CSS-viewport proxy for 200% zoom on a 1440px viewport; it is not a native browser zoom test. Native 200% browser zoom remains unverified. Capture used the muted Chromium config via `CAPTURE_SHELL_EVIDENCE=1 npx playwright test e2e/shell-evidence.spec.ts`.
