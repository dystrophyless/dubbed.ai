# Business requirements

Create an actual BR here only when a product requirement is being defined. Use [the BR template](../sdd/templates/business-requirements.md) and [guide](../sdd/guides/business-requirements-guide.md).

Naming: `BR-NNN_<slug>.md`, for example `BR-001_feature_outcome.md`. This example is not an allocated ID or an approved requirement.

Input: [the project brainstorm](../../brainstorm.md). Keep confirmed choices, proposals, assumptions, and unresolved questions distinguishable. No BR has been approved by installing the SDD package.
