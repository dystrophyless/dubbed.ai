# Specifications

Create behavior contracts using the [specification template](../sdd/templates/specification.md) and [guide](../sdd/guides/specifications-guide.md).

Naming: `SPEC-NNN_<slug>.md`. Check existing IDs before allocating one. No specification or ID has been created or approved by this setup.

Keep only a concise task index in each spec. Full unpublished task bodies belong in separate [task drafts](../task-drafts/README.md); published issue bodies own live task contracts and progress.
