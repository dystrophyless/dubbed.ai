# Components — the Dubbed kit

Search here before building anything. Live: `/styleguide` (every component, every state, EN/RU, 1440 and 390).
Values: `design-system/audit.md` → `frontend/src/styles/tokens.css`. Status: **Gate 1 approved by the owner on 2026-11-02** (styleguide reviewed on
localhost). Later changes to the kit go back through owner review.

## 1. affect-ui Clean / Light ports — `src/components/ui/affect/*`

Generated by `frontend/scripts/port-affect.py` from each source's `## Code` block. The script replaces only colours,
shadows, CSS easing and font families with tokens (JS easing strings for `element.animate` stay literal — the Web
Animations API cannot read CSS variables). Sizes, spacing, radii and markup are untouched. **Never edit a port by hand**;
re-run the script.

| Port | Source | Used for in Dubbed |
|---|---|---|
| `Button` | components/button | every action: primary / secondary / ghost / destructive; sm 24 · md 28 · lg 32 |
| `OtpInput` | components/otp-input | email verification code |
| `SegmentedControl` | components/segmented-control | language switch, view and tab switches, state switcher |
| `ProgressTracker` | components/progress-tracker | processing stages (role decided in Phase 4) |
| `NotificationStack` | components/notification-stack | in-app notices |
| `FilterMenu` | components/filter-menu | not used yet (ported for completeness; source of the checkbox and chip language) |
| `ProfileMenu` | components/profile-menu | account popover in the top bar |
| `ThinkingLoader` | components/thinking-loader | waiting pill with phases |
| `TipsPanel` | components/tips-panel | onboarding / help tips |
| `Skeleton`, `ShimmerText` | motion/shimmer-loader | loading states |
| `NumberTicker` | motion/number-ticker | credit balance |

Not ported (measured only): change-summary, comment-thread, decision-inbox, email-draft, message-actions, reaction-bar,
smart-recommendation, tool-call-card, text-reveal, grid-background.

## 2. Patches (documented deviations)

| # | Status | What | Why | Where |
|---|---|---|---|---|
| DUBBED PATCH 1 | **approved by the owner 2026-11-02** | Button on `(pointer: coarse)`: md / lg → 36px, sm → 32px | `button-clean` has no touch rule; every other Clean component grows its buttons to 34–36px on touch (`notification-stack-clean.md:469`, `decision-inbox-clean.md:437`, `tips-panel-clean.md:390`) | `src/components/ui/affect-patches.css` (overrides the port's own `--h`/`--px` from outside) |
| DUBBED PATCH 2 | **approved by the owner 2026-11-02** | Optional `labels` prop on otp-input, filter-menu, profile-menu, notification-stack; defaults = the original English | these ports print fixed English text (e.g. "Didn't get a code?", "Clear all", "Dismiss …") that no prop can change; the UI must be EN + RU | `port-affect.py` → `LABELS`; localised wrappers in `src/components/ui/kit/Localized.tsx` (exported as the public names) |

If the owner rejects a patch: remove its entry from the script / CSS and re-run `python scripts/port-affect.py`.
